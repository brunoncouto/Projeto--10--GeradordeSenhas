## 🇵🇹 Português

### 📌 Sobre o projeto

O **Password Generator** é uma aplicação web desenvolvida com HTML, CSS e JavaScript, que permite gerar senhas aleatórias e personalizadas de forma simples e rápida.

O utilizador pode definir o comprimento da senha e escolher os tipos de caracteres que pretende incluir, tornando a geração de senhas mais flexível.

### ✨ Funcionalidades

- 🔢 Definir o comprimento da senha.
- 🔠 Incluir letras maiúsculas e minúsculas.
- 🔢 Incluir números.
- 🔣 Incluir símbolos especiais.
- 🎲 Gerar senhas aleatórias.
- 📋 Copiar a senha gerada para a área de transferência.
- ⚙️ Mostrar ou ocultar as opções de personalização.

### 🛠️ Tecnologias utilizadas

| Tecnologia | Descrição |
|---|---|
| HTML5 | Estrutura da aplicação |
| CSS3 | Estilização da interface |
| JavaScript | Lógica e funcionalidades do gerador |

### 🚀 Instalação e execução

**1. Clonar o repositório**

```bash
git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
```

**2. Entrar na pasta do projeto**

```bash
cd SEU-REPOSITORIO
```

**3. Executar a aplicação**

Abrir o ficheiro `index.html` diretamente no navegador.

Não é necessária a instalação de dependências.

### 💻 Como utilizar

1. Abrir a aplicação no navegador.
2. Aceder às opções de personalização.
3. Escolher o comprimento desejado para a senha.
4. Selecionar os tipos de caracteres pretendidos.
5. Clicar em **Gerar Senha**.
6. Clicar em **Copiar Senha** para copiar o resultado.

### 📚 Conceitos de JavaScript aplicados

- Manipulação do DOM com `querySelector()`.
- Eventos com `addEventListener()`.
- Funções e Arrow Functions.
- Geração de números aleatórios com `Math.random()` e `Math.floor()`.
- Conversão de códigos ASCII com `String.fromCharCode()`.
- Manipulação de arrays com `push()` e `forEach()`.
- Manipulação de strings com `slice()`.
- Clipboard API para copiar conteúdo.

### 📌 About the project

**Password Generator** is a web application developed using HTML, CSS, and JavaScript that allows users to generate random and customized passwords quickly and easily.

Users can define the desired password length and choose which character types to include, making password generation more flexible.

- 🔣 Include special characters.
- 🎲 Generate random passwords.
